# Comunicación de problemas de seguridad

Para comunicar un posible problema de seguridad de DNIeNativeBridge, utiliza [el formulario privado de GitHub](https://github.com/bashrc0/DNIeNativeBridge/security/advisories/new). Incluye una descripción mínima, sin PIN, claves privadas, certificados personales ni información corporativa. Evita publicar detalles sensibles en un issue.

Si el formulario privado no está disponible, abre un issue solicitando un canal privado sin describir la vulnerabilidad ni incluir datos sensibles.

Los problemas que pertenezcan a una dependencia deben seguir también el procedimiento del proyecto original. Esta aplicación interactúa con claves de una tarjeta: antes de desplegar una compilación modificada, revisa el código y valida su comportamiento en tu entorno autorizado.
