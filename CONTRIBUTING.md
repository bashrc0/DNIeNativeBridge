# Contribuir

Documenta el modelo de Mac, versión de macOS, lector y versión compilada. Los resultados de lectura y los de autenticación deben distinguirse. No incluyas PIN, certificados personales, datos de identidad, perfiles VPN, direcciones internas ni capturas de portales corporativos en issues o pull requests.

Realiza las pruebas con tu tarjeta y un servicio para el que tengas autorización. Una prueba de compilación no valida la autenticación. Conserva las atribuciones, versiones y licencias de terceros al modificar dependencias.

Para cambios del controlador, incluye la explicación de la operación afectada y las comprobaciones realizadas, sin trazas de APDU ni contenido personal. Para problemas de seguridad, utiliza el contacto privado de `SECURITY.md`.
